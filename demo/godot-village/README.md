# Demo: Godot village

A tiny Godot 4.3 project for trying the skill in under a minute: a ground plane, a 1.7 m player capsule, a 45° camera, and an empty `HouseA_Placeholder` at (4, 0, 2).

Open this folder in Claude Code and ask:

> Make a cozy village house for this scene and replace the placeholder.

The agent surveys the project, writes a G1 plan, and **stops for your reply**. Everything it records lands in `.art-workflow/` and `art/workflow/` inside this folder.
