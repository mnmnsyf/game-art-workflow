# Controlled cottage → actual Godot lookdev

2026-11-01. From the maintainer's own indie project; project values here are evidence, not cross-project defaults. Artistic completion remains subject to G3, not a claim of equivalence to an AAA game.

1. A supplied style reference and an approved GPT scene concept replaced a yellow/toy-like visual target. G1 explicitly selected controlled Blender architecture plus GPT art rather than blind image-to-model retries. The user approved the concept, then the authored model; a timber/verge intersection was fixed as v2 and separately approved.
2. The 25934-triangle GLB retains separate walls, roof, door, glass and hardware. Neutral plaster is explicit albedo; GPT timber is base color. Original Tripo assets and both authored revisions stay available. The approved v2 GLB is not modified during renderer integration.
3. The actual map references a reusable cottage scene and courtyard kit. Collision follows measured walls, closed door and two low steps, with a visible lower apron matching the capsule-friendly slope. Source terrain/navigation remains; the ground uses a world-space path mask baked from existing routes, with gradual grass coverage.
4. Forward+ with sky fill, restrained SSAO, soft sunlight/shadows, ACES and MSAA was tested on the actual machine before changing the project default. GPT alpha foliage cards have mipmaps; instanced vegetation is authored with a real renderer and checked again in the executable. No local generative models are installed.
5. Real failures guided fixes: headless authoring omitted MultiMesh buffers; whole-mesh overrides hid new soil colors; a procedural ground color branch produced visible blocks; alpha-hash roof fading added salt-and-pepper noise; a trial local reflection probe leaked texture RIDs at exit. The shipped candidate uses actual instance buffers, active override updates, filtered data noise, smooth native-PBR fading with shadow proxies, and sky reflections.
6. Physical movement/occlusion checks and camera/dialogue checks passed. The native Windows export started with Vulkan/Forward+, rendered the authored model and foliage and exited cleanly. Review material distinguishes normal player framing, an optional avatar-free presentation camera, and the occlusion example. Warmed frame timing is only a short single-machine observation, not a platform guarantee.

Evidence kept in that project: the authoring script for the stylized cottage, Godot build scripts for the cottage and courtyard art, targeted engine tests for collision and camera, and a capture entry in its executable (project-specific, not a universal Godot flag). Authoring sources, native runtime resources and review records remain versioned separately. Source/field parameters belong in the project profile.
