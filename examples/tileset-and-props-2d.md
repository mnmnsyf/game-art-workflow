# Example: 2D Ground Tiling and Interior Prop Cut-outs

> User: "Make a grass tiling texture for my top-down pixel game, and split this interior concept into furniture I can place individually."

## 0. Survey

- Godot 4.x, TileMapLayer, 16 px grid, 16 px/m pixel density, Nearest filtering, no mipmaps.
- A project profile exists and style pack `meadow-v2` already has a palette and two anchors → don't re-ask about style.

## 1. G1 plan

| Output | Form | Acceptance |
| --- | --- | --- |
| Grass | 64×64 seamless tile, 4 variants against repetition | 3×3 preview shows no seam or brightness gradient; left/right and top/bottom seam error close to adjacent-pixel differences inside the image |
| Furniture | Bed, cabinet, table, and chairs, each a standalone transparent PNG | Real alpha, no white fringe on black/white/colored backgrounds; occluded parts painted in; foot sort point marked |

Key note: in the concept the table hides the chair legs, so **cropping cannot produce a complete chair** — it must be repainted using the concept as reference; slices with ground shadows cannot be used as standalone props; shadows are made separately or generated by the engine.

**Stop and wait for G1 approval.**

## 2. Grass

1. Generate a candidate → `tile_preview.py grass_v1.png --grid 3 --out review/`.
2. Report: the horizontal seam error is well above the interior baseline, plus a visible brightness gradient → a technical issue, fixed autonomously (offset by half, repair the seam, remove the low-frequency gradient), output v2 without changing the art style.
3. v2 metrics are near the baseline → submit the 3×3 preview for G2 with a v1/v2 comparison. **Stop and wait.**
4. Generate 3 variants with the same style pack and review them on a contact sheet.

## 3. Furniture cut-outs

1. First a split table (object, size, ground point, occlusion, parts to paint), approved along with G1.
2. Generate / edit piece by piece using the concept as design reference, with explicit invariants (colors, wood grain style, outline).
3. Run `alpha_check.py` on each piece:
   - One reports "no alpha channel, suspected RGB checkerboard" → fake transparency; send it back for editing, don't submit it for review.
   - One has 0 edge margin (the silhouette is cut off at the canvas edge) → re-export with padding.
4. Pieces that pass go on a contact sheet with black / white / magenta composites for G2. **Stop and wait.**

## 4. Integration and G3

- Grass goes into the TileSet with random variant probabilities; furniture are Sprite2D nodes with `offset` placing the foot on the sort origin and y_sort enabled.
- Collision covers only the footprint, not the whole image rectangle; the tall cabinet gets an extra foreground layer that can hide the character's upper body.
- Actual-camera screenshots: a character walks from in front of the bed to behind it and the sort order flips correctly → G3. **Stop and wait.**
